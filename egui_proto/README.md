# irealegui — Rust + egui прототип

Второй кандидат для переноса irealstudio (после Go/Glaze-веб-гибрида, который
фризил NVDA на ~10 сек). Чистый нативный desktop на Rust: egui + eframe с
фичей **accesskit**. Доступность к NVDA на Windows идёт через
accesskit_windows → UIA — без WebView2, без переключения деревьев, поэтому
фриза из первого прототипа быть не должно (это и проверяем).

## Запуск на Windows

Нужен Rust (stable): https://rustup.rs

```bat
cd egui_proto
cargo run --release
```

Первая сборка долгая (eframe + egui + accesskit), дальше кэш. Версия egui
жёстко зафиксирована `=0.27.2` — API проверен именно под неё.

## Что смотреть с NVDA

Окно: меню сверху (Файл / Правка / Вид / Справка), слева список песен +
поле поиска, в центре текст чарта, внизу статус.

1. `Tab` обходит кнопки, список, поле поиска — NVDA должна называть каждый
   элемент и его роль.
2. Меню: фокус на пункте + `Enter`/`Стрелка` — открывается подменю, читаются
   пункты; `Esc` закрывает. Пункты шлют сообщение в статусную строку (должна
   озвучиваться, как aria-live в вебе).
3. Список песен — навигация стрелками, выбор меняет заголовок чарта.
4. Текст чарта в центре — читается по строкам.
5. Главный вопрос: **нет ли 10-секундных фризов NVDA** на переходах между
   меню/кнопками/списком (в Go/Glaze-прототипе они были на любом переходе
   фокуса из веб-документа в нативное меню).

## Как это устроено

- `Cargo.toml`: `eframe = "=0.27.2"` + feature `accesskit`. В eframe 0.27
  accesskit включён и по умолчанию, но указан явно как намерение.
- `src/main.rs`: меню (`ui.menu_button`), плейлист (`selectable_value`),
  поле поиска (`TextEdit`), статус (`Label`), чарт (`Label` + monospace).
  Никакого HTML/JS — всё это нативные egui-виджеты, которые accesskit
  отдаёт NVDA как UIA-дерево.
- Подгрузка Segoe UI как fallback-шрифта: у встроенных шрифтов egui нет
  гарантии кириллицы, а UI на русском. Для NVDA не критично (текст читается
  из дерева), но чтобы окно не было «квадратами».

## Известные пределы прототипа

- Открыть/Сохранить — заглушки (в irealstudio это будет rfd или нативный
  диалог).
- Озвучивание чарта — заглушка (в irealstudio — TTS движок).
- Всё в одном `main.rs`, архитектура (модули, данные песен) — за рамками
  смоука: сейчас проверяется только доступность и отсутствие фризов.
