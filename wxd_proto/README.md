# irealwx — Rust + wxDragon (wxd_proto/)

Дымовой a11y-скелет перед переносом irealstudio на **Rust + wxWidgets**.
Проверяет на **Windows** главное, чего не дали два предыдущих кандидата:

- egui (см. `../egui_proto/`) — менюбар **ненастоящий**: NVDA читает верхние
  пункты как кнопки, `Alt` не открывает, стрелки не ходят. accesskit→UIA не
  моделирует меню.
- Go+Glaze с WebView2 (см. корневой `README.md`) — фриз NVDA ~10 сек на
  границе «веб-документ → нативное меню» (переключение IA2-деревьев).

wxDragon даёт **настоящее нативное меню** (wxWidgets → Win32 HMENU) и нативные
контролы — список, поля, текст — **без WebView2**, т.е. переключения деревьев
IA2 <-> UIA нет, и фриза, который мы ловили в glaze-гибриде, быть не должно.

Стек: [wxDragon](https://github.com/AllenDang/wxDragon) 0.9.21 — безопасные
Rust-биндинги; `wxdragon-sys` **статически** собирает vendored wxWidgets 3.3.3
→ на выходе один exe (~10–20 МБ), никакого рантайма рядом не нужно.

## Сборка на Windows

Код пишется так, чтобы собраться с первого раза, но **первая сборка долгая**
и требует полного C++-тулчейна. Честно о том, что происходит: `wxdragon-sys`
0.9.21 **не** скачивает готовые библиотеки — он качает исходники
wxWidgets 3.3.3 (zip, проверяется SHA-256) и компилирует их через CMake прямо
у тебя. Один раз — потом кэшируется, следующие сборки быстрые.

Требования (все стандартные, ставишь один раз):

1. **Rust MSVC-тулчейн**: `rustup default stable-msvc` (проверь
   `rustc --version`).
2. **VS 2022 Build Tools** с компонентом «Разработка классических приложений
   на C++» (даёт `cl.exe`, Windows SDK, CMake). В установщике VS добавь
   компонент **CMake** и, если есть, **Ninja** (без Ninja сборка пойдёт через
   MSVC-генератор — медленнее, но работает).
3. **LLVM** (`winget install LLVM.LLVM`) — `bindgen` генерирует FFI-биндинги
   при сборке и ищет `libclang.dll`. Если LLVM не находится сам, задай
   переменную окружения `LIBCLANG_PATH` на его `bin\` (например
   `C:\Program Files\LLVM\bin`).

Сборка и запуск — из **«x64 Native Tools Command Prompt for VS 2022»**
(пуск → так и называется; там уже на PATH `cl.exe` и `cmake.exe`):

```bat
cd glaze_proto\wxd_proto
cargo run
```

Первая сборка: качает и собирает wxWidgets 3.3.3 — 10–30 минут, норм.
Если `cmake` не находит `ninja`, поставь Ninja и добавь в PATH, либо ничего
не делай — сработает запасной MSVC-генератор. Окно не закрывай, пока не
увидишь окно программы.

Собрать один exe (для теста без консоли):

```bat
cargo build --release
:: exe: wxd_proto\target\release\irealwx.exe
```

## Что проверять с NVDA

Цель — убедиться, что меню **настоящее** и NVDA не фризит. Чек-лист:

1. **`Alt`** — открывается менюбар. NVDA объявляет меню и пункты
   Файл / Правка / Вид / Справка. Это уже не «кнопки», как в egui.
2. **Стрелки влево/вправо** ходят по верхним пунктам, **Вниз** открывает
   подменю, пункты читаются как пункты меню (с горячими клавишами).
3. **Enter** активирует пункт — в статус-строке внизу меняется текст
   (для «Сбросить статус» — «Готов.»). **Esc** закрывает меню, повторный
   **Alt** убирает менюбар с фокуса.
4. «Файл → Выход» — настоящее событие меню закрывает приложение
   (в glaze-гибриде это был мост в Go).
5. **Список песен** слева — настоящий нативный список: стрелки ходят по
   песням, NVDA объявляет выделенную, справа меняется заголовок чарта.
6. **Текст чарта** справа читается стрелками как обычный текст
   (readonly multiline). Для незрячего пользователя это главный рабочий
   инструмент irealstudio — проверь, что строки читаются целиком.
7. **Никакого фриза NVDA** при переходах фокус: меню → список → текст →
   снова меню. В glaze-гибриде на первом же `Alt` был стопор ~10 сек.

Если по п.7 есть фризы — wxDragon не спасёт и надо думать дальше. Если всё
чисто и меню настоящее — это архитектурный ответ для irealstudio.

## Заметки по коду

- Консоль не прячем (`wxdragon::main` держит её): если что-то не поднимется,
  ошибка будет видна в stdout, а не молча в трее.
- `SystemOptions::set_option_by_int("msw.no-manifest-check", 1)` глушит
  диалог про common controls на старте; нормальный манифест добавим в
  релизной сборке позже через build.rs.
- Содержимое (6 песен + чарт Rhythm Changes) идентично `egui_proto` — чтобы
  сравнение egui vs wx было честным.
- Widgets в wxDragon — `Copy`, нативные окна переживают Rust-обёртки, поэтому
  контролы можно спокойно захватывать в замыкания событий.
